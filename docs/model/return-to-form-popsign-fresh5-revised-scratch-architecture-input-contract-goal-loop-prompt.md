## Current Evidence

M3CY selected `scratch_motion_region_token_temporal_contract` as the preferred
future design direction because it materially differs from the failed late
fusion TCN path: it would preserve time-region tokens longer, add explicit
on-the-fly motion evidence from existing approved tensors, model cross-region
interaction before global pooling, and require representation-collapse
diagnostics before any future train-all.

M3CY also states the design review does not prove learnability and does not
authorize implementation, fitting, Brev compute, export, promotion, or claims.
Product downscope/no-recognition and stopping the scratch recognizer lane
remain explicit fallbacks if the contract cannot state a bounded, browser-
viable, no-pretrained route with evidence gates.

M3CR-M3CV show the old `scratch_region_temporal_late_fusion_tcn_contract_v1`
path is not justified for another fit: full train/validation/test collapse,
nonseparable train features, and fused-head representation collapse persisted
after data/split/tensor/sampler/loss/optimizer/checkpoint-selection checks.
