  pseudo-label.

- Stop immediately if the microprobe cannot beat the median box on train.

## Rejected Formulations

### Repeat M3AE-AG/M3AE-AI MLP Over Downsampled Full Frame

Rejected. The 393,989-parameter random-init MLP over a downsampled
full-frame reference failed train geometry after instrumentation was repaired:
train presence reached `1.0`, but train box MAE stayed
`0.18746726214885712`, far worse than the train median box
`0.04107142239809036`. Observer-249 also diagnosed saturated edge-like box
outputs and no useful geometry fit. Repeating this path would be a generic
training-smoke retry, which the current prompt forbids.

### Median-Only Constant Box As Detector

Rejected as a trainable Detector 0 formulation. The median box is the required
reference bar, but it is not a runtime presence detector and cannot justify a
crop-normalization ablation by itself. It remains the comparison baseline.

### Immediate Crop-Normalization Ablation

Rejected. The current trainable Detector 0 path has not yet beaten the
no-training train median box. Running ablation now would compare crop policies
using a detector formulation that has not shown train geometry competence.

### Packet Mutation Or Additional Row Review

Rejected for this slice. M3AE-AH found zero packet target-derivation
mismatches, zero tensor hash mismatches, and zero M3AE-AG smoke-row alignment
mismatches. M3AE-AJ reproduced a coherent low-variance target geometry. There
is no current packet/schema mismatch that invalidates the architecture
comparison.

### Pretrained Landmark/Detector Route

Rejected by project policy. MediaPipe, OpenPose, RTMPose, YOLO, pretrained
detector outputs, pretrained landmarks, pretrained backbones, and generated
pseudo-labels are outside the promoted lane.

## Selected Future Formulation

Selected next trainable formulation:
`anchor_residual_coordconv_union_target_microprobe_v1`.

The design replaces the failed unconstrained MLP box head with a scratch
spatial model that starts at the M3AE-AJ median box and learns bounded residual
geometry.

### Input Representation

- Source tensor key: `rgb_regions`.
- Frame: packet `frame_index` only.
- Region: `full_frame_reference`.
- Resolution: retain `96x96`, not the failed `32x32` downsample.
- Channels: RGB plus two deterministic coordinate channels `x_norm` and
  `y_norm` in `[0, 1]`.
- Normalization: float32 image values in `[0, 1]`; coordinate channels generated
  locally from pixel indices.
- No pretrained features, no optical flow, no external detector outputs, and no
  generated labels.

Rationale: the current failure is geometry fit, not packet coherence. A small
scratch convolutional model with coordinate channels has a spatial inductive
bias while staying within the no-pretrained lane.

### Model Sketch

```text
input: 5 x 96 x 96 tensor
stem: Conv2d(5, 16, kernel=3, padding=1) + GroupNorm + SiLU
block1: Conv2d(16, 32, kernel=3, stride=2, padding=1) + GroupNorm + SiLU
block2: Conv2d(32, 64, kernel=3, stride=2, padding=1) + GroupNorm + SiLU
block3: Conv2d(64, 64, kernel=3, stride=2, padding=1) + GroupNorm + SiLU
pool: adaptive average pool to 1x1
head: Linear(64, 5)
outputs: presence_logit, residual_x1, residual_y1, residual_x2, residual_y2
```

Parameter budget target: below 100k parameters. This is intentionally smaller
than the failed MLP while adding spatial structure.

### Target Encoding

- Presence target: packet target `presence` for
  `table_two_hand_union_or_contact_region`.
- Box anchor: M3AE-AJ train median box
  `[0.11999999731779099, 0.47999998927116394, 0.8199999928474426, 0.7200000286102295]`.
- Present-row residual target:
  `target_box_xyxy_norm - train_median_box_xyxy_norm`.
- Absent-row box residual loss: masked out.
- Predicted residual:
  `residual_scale * tanh(raw_residual)`.
- Residual scale:
  `[0.16, 0.16, 0.08, 0.18]`, covering the train coordinate spread with margin.
- Predicted box:
  `clamp(train_median_box + predicted_residual, 0.0, 1.0)`.

This makes the initial model equal to the median-box baseline and forces any
future pass claim to come from learned residual improvement, not from a weaker
absolute box parameterization.

### Initialization

- Convolution weights: Kaiming normal.
- Linear residual weights: zero.
- Linear residual biases: zero.
- Presence bias: `log(7 / 4) = 0.5596157879354227`, matching train target
  prevalence before learning.
- Random seed: fixed in the future runner and recorded in its receipt.

### Loss Terms

Future microprobe loss:

```text
total_loss =
  BCEWithLogitsLoss(presence_logit, target_presence)
  + SmoothL1Loss(predicted_residual, target_residual, beta=0.02) over present rows
  + 0.25 * (1 - IoU(predicted_box, target_box)) over present rows
```

Presence and box losses must be logged separately. Box losses must be computed
only over present union/contact targets.

### Local No-Spend Bounds

- Device: local CPU by default; MPS allowed only if available locally.
- Brev: no sync, SSH, remote training, or compute.
- Epoch cap: 300.
- Batch: full train split batch (`11` rows) for deterministic overfit proof.
- Optimizer: AdamW with learning rate `0.001`, weight decay `0.0001`.
- Gradient clipping: max norm `1.0`.
- Early stop: allowed after the success gate is met for at least 10 consecutive
  evaluation checkpoints.
- Required artifacts: row-level train/validation/test predictions, per-row
  errors, per-split metrics, comparison to M3AE-AJ, and no-pretrained/Brev
  boundaries.
